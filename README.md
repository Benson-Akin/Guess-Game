# 🎯 Guess Game

A fun and interactive number guessing game built with HTML, CSS, and JavaScript.

## 📖 Description

The Guess Game challenges players to guess a randomly generated number within a specified range. The game provides feedback after each guess, helping players find the correct answer.

## ✨ Features

- Random number generation
- User input validation
- Instant feedback on guesses
- Win/Loss detection
- Simple and responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎮 How to Play

1. Enter a number in the input field.
2. Click the **Guess** button.
3. Receive feedback:
   - Too High 📈
   - Too Low 📉
   - Correct 🎉
4. Continue guessing until you find the correct number.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Benson-Akin/Guess-Game.git
```

Navigate to the project folder:

```bash
cd Guess-Game
```

Open `index.html` in your browser.
